Program Keahlian

Terdapat 9 program keahlian unggulan di SMK Negeri 2 Yogyakarta yang disesuaikan dengan kebutuhan industri masa depan.

router

Sistem Informatika, Jaringan dan Aplikasi

SIJA • Program 4 Tahun • Akreditasi A

Program unggulan 4 tahun berstandar internasional. Menguasai cloud computing, keamanan siber, IoT, dan administrasi server. Lulusan langsung bersertifikasi Mikrotik Academy dan siap berkarir sebagai Network Engineer.

Kompetensi Keahlian

  • ✓ Merancang & instalasi LAN/WAN
  • ✓ Administrasi server Linux/Windows
  • ✓ Network Security & Cloud Computing
  • ✓ Web Database & CMS

Peluang Karir

  • ✓ Network Engineer
  • ✓ Cyber Security Analyst
  • ✓ Cloud Infrastructure Engineer
  • ✓ Web Developer
directions_car

Teknik Kendaraan Ringan Otomotif

TKRO • Program 3 Tahun • Akreditasi A

Jurusan otomotif terlengkap dengan dukungan penuh dari Mitsubishi Motors. Belajar langsung dengan unit kendaraan asli (Outlander Sport) dari CSR KTB. Kurikulum CBT & PBE standar industri global.

Kompetensi Keahlian

  • ✓ Pemeliharaan mesin (OHV, OHC, EFI)
  • ✓ Perbaikan sistem injeksi & kelistrikan
  • ✓ Perbaikan chasis & transmisi
  • ✓ Engine Tune Up konvensional & EFI

Peluang Karir

  • ✓ Mekanik Bengkel Resmi
  • ✓ Teknisi Otomotif Industri
  • ✓ Quality Control Kendaraan
  • ✓ Wirausaha Bengkel

Desain Komunikasi Visual / Multimedia

DKV • Program 3 Tahun • Akreditasi A

Pusat kreativitas digital SMKN 2 Yogyakarta. Menguasai fotografi, videografi, animasi 2D/3D, desain grafis, dan UI/UX. Dilengkapi studio produksi profesional dan software industri terkini.

Kompetensi Keahlian

  • ✓ Desain grafis & tipografi
  • ✓ Fotografi & videografi
  • ✓ Animasi 2D & 3D
  • ✓ Desain UI/UX

Peluang Karir

  • ✓ Graphic Designer
  • ✓ UI/UX Designer
  • ✓ Video Editor / Animator
  • ✓ Content Creator

Teknik Instalasi Tenaga Listrik

TITL • Program 3 Tahun • Akreditasi A

Ahli kelistrikan industri dan rumah tangga. Menguasai instalasi panel listrik, sistem kendali PLC, dan otomasi industri. Peluang karir terbuka lebar di BUMN kelistrikan dan perusahaan manufaktur.

Teknik Pemesinan

TP • Program 3 Tahun • Akreditasi A

Jurusan legendaris sejak era STM 1. Menguasai mesin bubut, frais, gerinda, dan CNC. Lulusan menjadi teknisi presisi tinggi yang dibutuhkan industri manufaktur pesawat, otomotif, dan permesinan.

Desain Pemodelan & Info Bangunan

DPIB • Program 3 Tahun • Akreditasi A

Arsitektur dan teknik sipil era digital. Merancang gedung bertingkat menggunakan AutoCAD, SketchUp, dan BIM (Building Information Modeling). Menjadi drafter dan desainer bangunan profesional.

engineering

Konstruksi Gedung, Sanitasi & Perawatan

KGSP • Program 3 Tahun • Akreditasi A

Ahli konstruksi bangunan dan utilitas gedung. Menguasai teknik konstruksi batu beton, pemasangan sanitasi, dan perawatan gedung bertingkat. Lulusan siap bekerja di proyek infrastruktur besar.

radio

Teknik Audio Video

TAV • Program 3 Tahun • Akreditasi A

Spesialis elektronika dan penyiaran. Menguasai sistem tata suara profesional, instalasi perangkat audio visual, perawatan peralatan broadcasting, dan teknologi elektronika terapan.

Teknik Geomatika

Geomatika • Program 3 Tahun • Akreditasi A

Menjadi surveyor profesional dan ahli pemetaan modern. Menguasai teknologi GPS, pemetaan drone, pengolahan data spasial dengan GIS, dan levelling presisi untuk proyek berskala besar.
